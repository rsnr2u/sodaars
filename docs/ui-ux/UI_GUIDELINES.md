# SODAARS - UI/UX Guidelines

## Frontends
1. **Provider Portal (`frontend/provider`)**:
   - Primary operational hub for outdoor advertising media owners.
   - Built with React, TypeScript, Vite, Tailwind CSS / Custom UI, React Hook Form, Zod, and Recharts.
   - Core modules: Inventory map (Leaflet), Booking calendar, Availability matrix, Enquiries pipeline, Quotation builder.

2. **Admin Portal (`frontend/admin`)**:
   - Governance and oversight portal for SODAARS platform operations.
   - Built with React, TypeScript, Vite, Tailwind CSS / Custom UI, React Hook Form, Zod.
   - Modules: Provider verification, Subscription plan configurations, Platform metrics.

3. **Public Directory (`website/directory`)**:
   - Public SEO-friendly provider discovery portal.
   - Built with Next.js (App Router), React, TypeScript.
   - Clean, lightweight browsing by city, district, and advertising media category.
